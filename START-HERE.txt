SOMAS: project AI team release

Each deployed business service now includes its own real AI team and a private owner panel at /team. The AI-team source is separated in lib/ai-team/.

UPGRADE YOUR EXISTING somas FOLDER
1. Back up your folder and database. Keep your .env.cloudflare and original encryption key.
2. Replace source files with this archive. Do not replace your local environment file or database.
3. In your somas folder run:
   npx pnpm@11.25.0 install --frozen-lockfile --prod=false
   node --env-file=.env.cloudflare scripts/neon-migrate.mjs
   npx pnpm@11.25.0 run build:cloudflare
   npx wrangler login
   node --env-file=.env.cloudflare scripts/deploy-independent.mjs

Do not re-import a backup into an existing Neon database. The new migration only adds a column. Do not change your immutable owner ID or APP_DATA_KEY.

PROJECT DEPLOYMENT
Sign in -> create a project -> connect your AI provider -> choose a root domain -> connect Cloudflare -> publish -> Open AI team on my domain -> Resume.
Your domain must be registered and active in Cloudflare. New project services do not use generated subdomains. Registration checkout stays with the domain owner.
The project starts paused. Publishing installs your provider key as a private Worker secret in your Cloudflare account. Pause or revoke that key at its provider to stop use; deleting it from SOMAS alone does not revoke the deployed copy.

The current team tools improve and publish structured website content. Arbitrary application coding remains a future feature.

Read docs/project-ai-team-v1.md and docs/cloudflare-neon.md.
