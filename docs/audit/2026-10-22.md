## Source findings and repair direction

1. Shared organization planner is explicitly planning-only. Implement a separate durable runtime; never translate plans into execution success.
2. Daily cron audits at most three projects; no mission comparison, lease/retry or useful-work queue. Persist mission, criteria, gaps and bounded jobs; use database-backed scheduling independent of sessions.
3. Chat response disappears on refresh. Persist owner requests and Manager responses with task links.
4. Command-center files are a disconnected design preview. Integrate authenticated records and real events; distinguish queued/working/waiting/blocked/failed/completed/idle.
5. Provisioning count outside a transaction can exceed three under concurrency. Enforce at the database boundary.
6. Concurrent proposals have no source-release check and can overwrite intervening changes. Pin proposal base release and reject stale approval.
7. JSON payload reads allocate the entire request before checking the final length. Bound streaming bytes.
8. Browser report endpoint accepts owner assertions. Distinguish externally submitted reports from independently executed browser evidence.
9. Root UI only prepares plans. Add administrator-only operational metadata without granting access to customer conversations/specs.
10. No isolated coding provider or independently hosted deployment adapter configured. Fail closed with specific blockers; prepare standalone artifacts, never label a package as deployed.
