SYSTEM DESIGN

How SOMAS v2 works

Root Manager → Customer instance → Continuous improvement

The central platform provisions a private application workspace with a Manager, Assistant and Virtual Customer. Customer-facing sites publish at /s/slug on the same Cloudflare deployment; each customer's agents, policies, and content live in Neon PostgreSQL.

The Manager assigns specialists; the Assistant relays owner requests; the Virtual Customer evaluates user experiences. An AI gateway can use centrally held keys. Neural policy training happens only from owner-labelled examples.

Not yet automatic: unrestricted code generation, external domain provisioning, actual browser traversal in the Worker, autonomous neural promotion, merchant checkout, and background research.
